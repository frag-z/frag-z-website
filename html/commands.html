Command Reference

Name Alias Description
set_gravity sg Set the gravity to a given number this unit is m/s^2
set_rocket_explosion_radius srer set the explosion radius of all rockets
set_rocket_force srf set the force that gets applied when a rocket explodes
set_enemy_popoff_normalized_distance_leniancy_power sepndlp when there is an explosion we measure the distance to the explosion in a linear fashion in the range [0, 1] this distance is linear, so instead we add a power to make it a curve
set_enemy_popoff_force sepf the popoff force is a force that helps get enemies off the ground when we shoot them with rockets
set_sniper_rifle_force ssrf sets the force applied to enemies when shot by the sniper rifle
set_shotgun_force ssrf sets the force applied to enemies when shot by the shotgun
set_lightning_gun_force slgf sets the force applied to enemies when shot by the lightning gun
set_rocket_velocity srv set the rocket velocity
set_grenade_velocity sgv set the grenade velocity
set_jump_force sjf set the jump force
set_quick_succession_jump_force sqsjf set the quick succession jump force
set_max_walk_velocity smwv set the max walking velocity
set_direction_snappiness sds set the direction change snappiness
set_movement_acceleration sma set the movement acceleration
ready_up ru ready up the player
